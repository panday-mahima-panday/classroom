# Classroom - Web Development Practice

## Overview

This repository contains my classroom practice work and assignments related to web development. It includes HTML pages, CSS styling, navigation bars, and practice exercises created while learning frontend development.

## Topics Covered

- HTML fundamentals and page structure
- CSS styling and layouts
- Navigation bar design
- Web page development and practice assignments
- Frontend development basics

## Technologies Used

- HTML5
- CSS3

## Project Structure

- `class1.html`, `class2.html` – HTML practice files
- `index.html` – Main webpage
- `level2.html`, `level3.html`, `level4.html` – Practice exercises
- `style.css`, `style2.1.css`, `style.nav.css` – CSS styling files

## Purpose

The purpose of this repository is to practice and improve my HTML and CSS skills by building webpages and completing frontend development exercises.
